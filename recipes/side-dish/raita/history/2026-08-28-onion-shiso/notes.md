# 玉ねぎと大葉のライタ

## 位置づけ

プレーンヨーグルトに玉ねぎ、スパイス、大葉、レモン汁を混ぜた簡単なライタ。
バスマティライスが炊けるまでの前菜として作り、実食して成立を確認した。

## 1食分

| 材料・調味料 | 分量 |
| --- | ---: |
| プレーンヨーグルト | 100g |
| 冷凍玉ねぎ | 約20g |
| クミン | 小さじ1/2 |
| コリアンダー | 小さじ1/2 |
| カルダモン | 小さじ1/4 |
| 大葉 | 適量 |
| レモン汁 | 小さじ1程度 |

## 調理方法

1. 材料をすべて混ぜる。
2. 味を見て、そのまま食べる。

## 所感

- 想像以上に美味しく、単体の副菜として十分成立した。
- バスマティライスやカレーの付け合わせだけでなく、朝食への転用候補にもなる。
- 今回のクミンは乾煎りせず使用した。次回は乾煎りして香りの違いを確認したい。
- 蜂蜜やシナモンを少量加える方向も候補だが、今回は未使用。

## 次回確認したいこと

- クミンを乾煎りした場合の香りの差。
- 蜂蜜を少量加えた場合、酸味の角がどの程度丸くなるか。
- 朝食用途では、卵や作り置きの鶏むね肉などと組み合わせた際の満足感を確認する。
