# クローブ強めの大鍋チャイ

## 調理日

2026-07-25

## 位置づけ

スープを煮込んでいる間に並行して作った、約1.1L仕込みの大容量チャイ。
粉末スパイスを先に水で煮出し、アッサム茶葉、牛乳の順で加える構成とした。

標準レシピよりクローブを強めにし、甘味は必須とせず無糖も候補にした。

## 実際に使用した材料

| 材料 | 分量 | 備考 |
| --- | ---: | --- |
| 水 | 500ml | スパイスと茶葉を煮出す |
| 牛乳 | 約600ml |  |
| アッサム茶葉 | 小さじ4 |  |
| シナモンパウダー | 小さじ1/2 |  |
| クローブパウダー | 小さじ1/4 | 今回は多め |
| カルダモンパウダー | 小さじ1 |  |
| ジンジャーパウダー | 小さじ1/2 |  |
| 砂糖または甘味料 | 未確認 | 無糖も候補。最終投入の有無は未記録 |

## 実際の手順

1. 鍋に水500ml、シナモン、クローブ、カルダモン、ジンジャーを入れた。
2. スパイスだけで先に煮出した。
3. アッサム茶葉小さじ4を加えて煮出した。
4. 牛乳約600mlを加えた。
5. 甘味は最後に調整する予定としたが、実際に加えたかは未記録。

## 結果・所感

- 標準の1杯分ではなく、複数杯をまとめて作る約1.1L仕込みとなった。
- クローブを普段より多めにした。
- しっかり甘くするには砂糖量が多くなるため、無糖で飲む案も検討した。
- 完成後の味、香り、甘味の有無は音声ログに記録されていない。

## 次回の確認事項

- 無糖で満足できるか
- クローブ小さじ1/4が強すぎないか
- カルダモン小さじ1とのバランス
- アッサム小さじ4で牛乳600mlに負けない濃さになるか
- 約1.1Lを作り置きした場合の保存方法と再加熱後の香り
- 実際に使用した砂糖または甘味料の種類と量
