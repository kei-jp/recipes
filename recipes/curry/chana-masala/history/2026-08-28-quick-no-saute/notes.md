# 炒めず15分で作る簡易チャナマサラ

## 位置づけ

バスマティライスの炊き上がり待ち約15分で作った、炒め工程なしの簡易チャナマサラ。
材料とスパイスを鍋で混ぜて加熱するだけで成立し、作り置きした鶏むね肉のソースとして実食したところ非常に相性が良かった。

本格的なチャナマサラの再現ではなく、作り置き・省力化を優先したスパイストマト豆ソースとして記録する。

## 材料

| 材料 | 分量 | 備考 |
| --- | ---: | --- |
| 冷凍玉ねぎ | 約100g | おおよその記憶 |
| ひよこ豆 | 約100g | おおよその記憶 |
| トマト缶 | 1缶 | 種類は未記録 |
| グリーンピース | 約30g | 冷凍・生などの形態は未記録 |

## スパイス・調味料

| スパイス・調味料 | 分量 | 確度 |
| --- | ---: | --- |
| クミン | 小さじ1 | 記憶ベース |
| コリアンダー | 小さじ1 | 記憶ベース |
| カイエンペッパー | 小さじ1/2 | 使用したか確信なし。次回はこの量で試す候補 |
| 黒胡椒 | 小さじ1/4 | 記憶ベース |
| 塩 | 小さじ1 | 記憶ベース |

クミンとコリアンダーがホールかパウダーかは今回の会話では確定できなかったため、種類は未記録とする。

## 調理方法

1. 冷凍玉ねぎ、ひよこ豆、トマト缶、グリーンピースを鍋へ入れる。
2. クミン、コリアンダー、黒胡椒、塩を加える。
3. カイエンペッパーは今回使用したか記憶が曖昧。次回再現時は小さじ1/2を候補とする。
4. 炒め工程は行わず、そのまま全体を混ぜて加熱する。
5. 好みの濃度まで煮詰めて完成。

## 評価

- 炒め工程なしでも十分おいしく成立した。
- 鶏むね肉と合わせるソースとして非常に良かった。
- トマト、豆、スパイスの組み合わせで、淡白な鶏むね肉を食べやすくできる。
- 約15分で作れるため、朝食や作り置きへの転用もしやすい。

## 次回確認したいこと

- カイエンペッパー小さじ1/2を確定採用した場合の辛味。
- クミンとコリアンダーをパウダーで統一するか、クミンのみホールを使うか。
- 塩は煮詰め後に最後に調整した方が、作り置き時の塩辛さを避けやすいか。
- 鶏むね肉用ソースとして使う場合の最適な煮詰め具合。
