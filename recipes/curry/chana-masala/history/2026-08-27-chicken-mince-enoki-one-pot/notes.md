# 鶏むねミンチとえのきの簡単チャナマサラ

## 位置づけ

鶏むねミンチ、ひよこ豆、えのき、トマト缶をまとめて加熱して作った、作り置き向けのチャナマサラ風カレー。
複雑な工程を設けず、材料とスパイスを一つの鍋で加熱して仕上げた。

## 材料

| 材料 | 分量 | 備考 |
| --- | ---: | --- |
| 鶏むねミンチ | 約200g |  |
| ひよこ豆 | 約200g |  |
| えのき | 1株 |  |
| ホールトマト | 1缶 |  |
| にんにく | 2かけ程度 |  |
| 生姜 | 1かけ程度 |  |
| オニオンオイル | 大さじ1 | 加熱用 |

## スパイス

### パウダー

| スパイス | 分量 |
| --- | ---: |
| クミン | 小さじ3 |
| コリアンダー | 小さじ4 |
| カイエンペッパー | 小さじ1/2 |
| ターメリック | 小さじ2 |
| カルダモン | 小さじ1 |

### ホール

| スパイス | 分量 | 備考 |
| --- | ---: | --- |
| コリアンダー | 小さじ1 | ホール |
| ブラックペッパー | 小さじ1 | ホール |
| クミンシード | 小さじ1 | テンパリング用として使用 |
| マスタードシード | 小さじ1 | テンパリング用として使用 |

## 調理方法

1. 鍋に材料、オニオンオイル、パウダースパイス、ホールスパイスを入れる。
2. 全体を混ぜながら加熱する。
3. 鶏むねミンチに十分火が通り、全体がなじむまで加熱して完成。

今回はテンパリング用のクミンシードとマスタードシードも含め、独立した複雑な工程にはせず、一つの鍋でまとめて加熱した。

## 所感

- 手順が単純で、作り置き向けとして扱いやすい。
- トマト、ひよこ豆、鶏むねミンチ、えのきでボリュームを出しやすい。
- 今回は調理後に記憶から分量を復元しているため、次回は調理中に記録して再現性を上げる。

## 次回確認したいこと

- スパイス分量を調理時点で記録する。
- クミンシードとマスタードシードを別途テンパリングした場合の香りの差を確認する。
- 塩分量を明示して記録する。
