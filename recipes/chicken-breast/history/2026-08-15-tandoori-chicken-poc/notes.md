# タンドリーチキン風 鶏むね肉PoC

## 目的

鶏むね肉600gを対象に、タンドリーチキン風のスパイス配合を共通化し、以下の4条件で漬け込み有無と加熱方法の差を比較する。

1. 漬け込みあり × 焼き
2. 漬け込みなし × 焼き
3. 漬け込みあり × 炊飯器保温90分
4. 漬け込みなし × 炊飯器保温90分

現時点ではPoC中のため、評価・レビューは確定させない。

## 材料

| 材料 | 分量 |
| --- | ---: |
| 鶏むね肉 | 600g |
| プレーンヨーグルト | 100g |
| 塩 | 小さじ1.5 |
| レモン汁 | 小さじ2 |
| にんにく | 1〜2片 |
| 生姜 | 約10g |

## スパイス

| スパイス | 分量 |
| --- | ---: |
| クミン | 小さじ1.5 |
| コリアンダー | 小さじ2 |
| ターメリック | 小さじ1/2 |
| カイエンペッパー | 小さじ1/2 |
| ガラムマサラ | 小さじ1 |
| カルダモン | 小さじ1/4 |
| 黒胡椒 | 少々 |

## 下準備

1. ヨーグルト、塩、レモン汁、にんにく、生姜、スパイス類を混ぜて調味液を作る。
2. 漬け込みあり条件では、鶏むね肉に調味液を絡めて冷蔵庫で漬け込む。
3. 漬け込みなし条件では、加熱前に調味液を絡め、そのまま加熱へ進む。

## 加熱条件

### 焼き

フライパン等で表面に焼き色を付けながら、中まで十分に加熱する。

### 炊飯器保温

炊飯器の保温モードで90分を基準に加熱する。

## 備考

- 作り置き・弁当用途を想定し、翌日以降の味・食感も比較対象とする。
- 焼きは香ばしさ、保温はしっとり感と省力性を主な確認ポイントとする。
- 評価結果がまとまるまでは `standard.md` へ反映しない。
