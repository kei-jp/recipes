# 八角とクミンのルーローハン風塩麹だれ鶏むね肉

## 位置づけ

2026-08-23のスターアニス塩麹だれをベースに、ルーローハン風へ寄せて再度作った鶏むね肉の記録。
今回の分量は調理後に記憶から復元したもので、一部はおおよその値または未確認である。

同日に作った簡易チャナマサラをソースとして合わせたところ、非常に相性が良かった。

## 材料・調味液

| 材料・調味料 | 分量 | 確度 |
| --- | ---: | --- |
| 鶏むね肉 | 未記録 | 今回の重量は未確認 |
| 水 | 約200ml | 記憶ベース |
| 液体塩麹 | 約80ml | 記憶ベース |
| 醤油 | 大さじ2程度 | 記憶ベース |
| 酒 | 大さじ1程度 | 記憶ベース |
| スターアニス（八角） | 2片 | 記憶あり |
| クミン | 小さじ1〜2程度 | 分量の記憶が曖昧 |
| 黒胡椒 | 小さじ1/2程度 | 記憶ベース |
| にんにく | 1かけ程度 | 記憶ベース |
| 生姜 | 1かけ程度 | 記憶ベース |

塩と砂糖は、今回は入れなかった可能性が高いが確信がないため、使用量としては記録しない。

## 未確認のスパイス

クローブを入れたような記憶もあるが、実際に投入した確信はないため使用材料には含めない。
シナモンも前回から候補に挙がっていたが、今回の使用有無は未確認である。
次回は調理時点で投入スパイスを記録し、八角・クミン・黒胡椒を軸に、クローブやシナモンの有無を比較できるようにする。

## 調理方法

今回の会話から確実に復元できたのは調味液の構成までで、漬け込み時間と加熱条件は再確認できなかったため未記録とする。
鶏むね肉の標準レシピは炊飯器保温調理だが、今回も同条件だったとは推測せず、履歴には具体条件を補完しない。

## 評価

- 鶏むね肉単体として成立している。
- 同日に作った簡易チャナマサラをソースとして合わせると非常に良かった。
- 八角を軸にしつつ、クミンと黒胡椒を加えた香りは、トマト系のチャナともつなげやすい。

## 前回との主な差分

2026-08-23の履歴では、液体塩麹80ml、水220ml、醤油大さじ1、スターアニス2片を記録していた。
今回は記憶ベースで、水約200ml、醤油大さじ2、酒大さじ1、クミン小さじ1〜2、黒胡椒小さじ1/2、にんにく1かけ、生姜1かけが候補として追加された。

## 次回確認したいこと

- クミンを小さじ1と小さじ2のどちらに固定するか。
- クローブやシナモンを実際に追加した場合、八角とのバランスがどう変わるか。
- 醤油大さじ2で塩味が強くならないか。塩麹80mlとの組み合わせを確認する。
- 漬け込み時間と加熱条件、投入スパイスを調理時点で記録する。
