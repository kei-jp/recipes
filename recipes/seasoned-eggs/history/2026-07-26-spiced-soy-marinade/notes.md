# スパイス味付け卵 調味液メモ

## 作成日

2026-07-26

## 材料

| 材料 | 分量 |
| --- | ---: |
| 水 | 250 ml |
| クミン | 小さじ1 |
| コリアンダー | 小さじ1 |
| カイエンペッパー | 小さじ0.5 |
| フェヌグリーク | 小さじ1/8程度 |
| ターメリック | 小さじ0.5 |
| 塩 | 小さじ1 |
| 醤油 | 30 ml |

## 手順

1. 水にクミン、コリアンダー、カイエンペッパー、フェヌグリーク、ターメリック、塩を加える。
2. 沸騰させ、スパイスを抽出する。
3. 抽出後に醤油30 mlを加える。
4. 調味液を冷まし、ゆで卵を漬ける。

## 備考

ターメリックが必要かは未確定。次回、ターメリックなしの配合も比較候補。
