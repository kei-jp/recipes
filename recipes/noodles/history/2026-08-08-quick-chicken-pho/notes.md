# 鶏ひき肉の簡易フォー

## 位置づけ

家庭で手間をかけずに作るフォーの試作記録。
ホールスパイスの乾煎りや生の生姜などを省略し、普段の昼食や職場への持参にも使える程度の簡便さを優先した。
味は概ね満足。今回茹でた麺の一部を冷蔵・冷凍し、保存後の食感を確認する。

## 材料

| 材料 | 分量 | 備考 |
| --- | ---: | --- |
| フォー（乾麺） | 130g | 茹で上がりの約半量を1食分として使用。残りは冷蔵・冷凍テストへ |
| 水 | 800ml | スープ用 |
| 鶏むねひき肉 | 約50g | スープと一緒に加熱 |
| 冷凍カット玉ねぎ | 約30g | 生玉ねぎを切る工程を省略 |
| 刻みねぎ | 適量 | 仕上げ |
| 白こしょう | 適量 | 仕上げ |

## スパイス・調味料

| 材料 | 分量 | 備考 |
| --- | ---: | --- |
| コリアンダー | 小さじ1 | お茶パックに入れて抽出 |
| クミン | 小さじ1/2 | お茶パックに入れて抽出 |
| カルダモン | 小さじ1/4 | お茶パックに入れて抽出 |
| クローブ | 小さじ1/4 | お茶パックに入れて抽出 |
| スターアニス | 1個 | お茶パックに入れて抽出 |
| シナモン | 小さじ1/2 | 入れ忘れに気づき、後からパックに入れずそのまま投入 |
| ジンジャーパウダー | 小さじ1/2 | 生姜の代用 |
| ナンプラー | 大さじ1.5 | 仕上げの味付け |
| 塩 | 小さじ1/2 | 味付け |
| 砂糖 | 小さじ1/2 | 味付け |

## 手順

1. コリアンダー、クミン、カルダモン、クローブ、スターアニスを乾煎りせず、お茶パックへ入れる。
2. 鍋に水800ml、スパイスのお茶パック、冷凍カット玉ねぎ約30g、鶏むねひき肉約50g、ジンジャーパウダー小さじ1/2を入れて加熱する。
3. 入れ忘れていたシナモン小さじ1/2を途中から直接加える。
4. 長時間煮込まず、スパイスと鶏肉から十分に香り・旨味が出たところでナンプラー大さじ1.5、塩小さじ1/2、砂糖小さじ1/2を加える。
5. フォー130gを別鍋で柔らかくなるまで茹でる。
6. 茹でたフォーの約半量を器に盛り、スープと鶏ひき肉を加える。
7. 刻みねぎと白こしょうを振って仕上げる。
8. 残った麺は冷蔵用と冷凍用に分け、保存後の食感を比較する。

## 所感

- 手順をかなり省略したが、フォーとして概ね満足できる味になった。
- スパイスを乾煎りせず、お茶パックでまとめて抽出する方法でも十分実用的だった。
- 冷凍玉ねぎと鶏むねひき肉を使うことで、切る工程をほぼ省略できた。
- 鶏ひき肉は具材になるだけでなく、スープへ旨味を加える用途として手軽で使いやすい。
- シナモンは途中投入になったが、今回の仕上がりでは大きな問題はなかった。
- ナンプラー大さじ1.5、塩・砂糖各小さじ1/2の味付けは今回の構成では成立した。

## 反省点・次回調整候補

- 生姜はジンジャーパウダーでも成立したが、爽やかな香りを出すなら生姜チューブまたは生の生姜を試す。
- レモン汁を用意していたが入れ忘れた。次回は仕上げに加えて酸味による輪郭の変化を確認する。
- パクチーは未使用。入手した際にトッピングとして試す。
- もやし、ニラも候補。ただし少量使用では余りやすいため、冷凍や他料理との共用を前提に検討する。
- 輪切り唐辛子を仕上げに少量加え、スープの味が締まるか試す。
- 茹でたフォーの冷蔵・冷凍耐性は未評価。職場への持参やストック運用が可能か、今回保存した麺で食感を確認する。
