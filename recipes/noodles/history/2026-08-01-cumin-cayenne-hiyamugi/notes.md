# クミンとカイエンの冷や麦

## 位置づけ

市販のめんつゆへ少量のスパイスを加えた、手軽な冷たい麺の実験記録。
素麺を予定していたが、実際には冷や麦を使用した。

## 材料

| 材料 | 分量 | 備考 |
| --- | ---: | --- |
| 冷や麦 | 1食分 | 表示どおりに茹で、冷水で締める |
| めんつゆ | 1食分 | 濃縮タイプは表示どおりに希釈する |
| クミンパウダー | 小さじ1/4 | めんつゆへ加える |
| カイエンペッパー | ひとつまみ | 辛味のアクセント |
| 刻みねぎ | 適量 | トッピング |
| 刻み海苔 | 適量 | 湿気て香りが弱くなっていたため全量使用 |
| かまぼこ | 適量 | あったものを使用 |

## 手順

1. 冷や麦を表示どおりに茹で、冷水でしっかり締める。
2. めんつゆを表示どおりに希釈する。
3. めんつゆへクミンパウダー小さじ1/4とカイエンペッパーひとつまみを加えて混ぜる。
4. 冷や麦を盛り、刻みねぎ、刻み海苔、かまぼこをのせる。

## 所感

- 和風のめんつゆにクミン小さじ1/4とカイエンひとつまみを加える組み合わせは成立した。
- クミンを増やしすぎず、香りの変化が分かる程度に留めたのが良かった。
- 冷や麦は素麺より少し太く、スパイス入りのつゆにも負けにくかった。
- 海苔は湿気て香りがほぼ飛んでいたが、傷んではいなかったため全量消費した。

## 次回調整候補

- コリアンダーパウダーをひとつまみ加え、爽やかさが増すか試す。
- レモン汁を小さじ1程度加え、夏向けの酸味を足す。
- ごま油は数滴から試し、香りを強くしすぎない。
