# 鶏むね・ひよこ豆・セロリのトマトスパイススープ

## 位置づけ

冷凍ひよこ豆、飴色玉ねぎストック、鶏むね肉、セロリを使った作り置きスープ。
セロリの葉をホールトマトと一緒にブレンダーへかけ、香りをスープ全体へ広げる。
約5〜6食分を想定する。

## 材料

### 具材・ベース

| 材料 | 分量 | 備考 |
| --- | ---: | --- |
| 鶏むね肉 | 約200g | 食べやすく切る |
| 加熱済みひよこ豆 | 約200g | 冷凍のまま完成後に加え、余熱で解凍した |
| 飴色玉ねぎ | 約200g | 作り置きストック |
| セロリ | 2本 | 茎は切って具材、葉はブレンダーへ |
| しめじ | 1パック | 石づきを除いてほぐす |
| ホールトマト缶 | 1缶 | セロリの葉と一緒にブレンダーへ |
| 水 | 1.2L | 煮込み用 |
| 油 | 適量 | テンパリング・炒め用 |

### スパイス・調味料

| 材料 | 分量 | 使用タイミング |
| --- | ---: | --- |
| クミンシード | 小さじ1 | 最初にテンパリング |
| クミンパウダー | 小さじ2 | 煮込み前 |
| コリアンダーパウダー | 小さじ3 | 煮込み前 |
| カイエンペッパー | 小さじ1 | 煮込み前 |
| ジンジャーパウダー | 小さじ1 | 煮込み前 |
| ローレル | 2枚 | 煮込み時 |
| 塩 | 小さじ4 | 玉ねぎスープの素の塩分もあるため次回は様子を見て調整 |
| 玉ねぎスープの素 | 小さじ1 | 旨味補助。塩気が強い可能性あり |
| レモン汁 | 小さじ2 | 仕上げ予定 |

## 手順

1. ホールトマトとセロリの葉をブレンダーにかける。
2. 鍋に油を入れ、クミンシード小さじ1をテンパリングする。
3. 鶏むね肉を炒める。
4. ブレンダーにかけたホールトマトとセロリの葉、飴色玉ねぎ、水1.2Lを加える。
5. クミン、コリアンダー、カイエン、ジンジャー、ローレル、塩、玉ねぎスープの素を加えて加熱する。
6. しめじとセロリの茎を加え、火が通るまで煮る。
7. 火を止めた後、冷凍ひよこ豆約200gをそのまま加え、余熱で解凍する。
8. 仕上げにレモン汁小さじ2を加え、味を見て調整する。

## 所感

- セロリの風味がスープに合い、かなり好みだった。
- 葉をトマトと一緒にブレンダーへかける方法は、香りと見た目の両面で有効そう。
- 次回はセロリの茎もブレンダーへかけ、ほかの野菜を具として残す構成も試せそう。
- キャベツは在庫があると思っていたが、実際にはなかった。
- ビーツパウダーは湿気てペースト状になっていたため使用しなかった。
- 冷凍ひよこ豆を完成後に加えても、余熱で問題なく解凍できた。

## 次回調整候補

- 玉ねぎスープの素を使う場合は、塩を小さじ3以下から始める。
- セロリの茎もブレンダーにかけ、ほかの野菜を追加する。
- レモン汁は小さじ2を基準に、食べる直前に少量追加してもよい。
