# 水と追いスパイスで調整したグリーンカレー

## 調整日

2026-07-30

## 位置づけ

2026-07-27に作成した濃厚なココナッツグリーンカレーの残り約3.5食分を、水と追加スパイスで食べやすく調整した版。

調整前のカレーを少し食べた後に手を加えたため、追加量は厳密な全量比ではなく、残量約3.5食分に対する実測値。

## 元になったカレー

- [濃縮ココナッツグリーンカレー 初回試作](../2026-07-27-concentrated-coconut-green-curry/notes.md)

## 追加した材料

| 材料 | 分量 |
| --- | ---: |
| 水 | 300 ml |
| コリアンダー | 小さじ1 |
| クミン | 小さじ1 |
| カイエンペッパー | 小さじ1 |

カイエンペッパーは、濃さへの怒りを込めた追加。

## 調整手順

1. 残っていた濃厚なグリーンカレー約3.5食分を鍋に戻す。
2. 水300 mlを加えて全体をよく混ぜる。
3. コリアンダー小さじ1、クミン小さじ1、カイエンペッパー小さじ1を加える。
4. 加熱しながら均一になるまで混ぜ、濃度と味を確認する。

## 変更点

- 水300 mlでココナッツの濃さと、オートミール・野菜由来のもったり感を緩和。
- 希釈で薄くなる香りを、コリアンダーとクミンで補強。
- カイエンペッパーを追加し、重さより辛味が先に立つ方向へ調整。

## 備考

- 調整前に一部を食べているため、元レシピ全量に適用する場合は水と追加スパイスを少し増やす余地がある。
- 次回は完成後の救済ではなく、最初からココナッツミルク400 mlに対して水300〜400 mlを加える。
- さらに軽くしたい場合は、1食分の量を減らすか、ココナッツミルク自体を200 ml程度に減らして水やトマトで補う。
