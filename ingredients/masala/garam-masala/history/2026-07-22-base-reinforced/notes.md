# 土台を強化したガラムマサラ

## 作成日

2026-07-22

## 位置づけ

料理の仕上げに振りかけ、日が経ってスパイスの香りが弱くなった料理を補完するための試作。

## 配合

| スパイス | 分量 |
| :-- | --: |
| クミン | 小さじ3 |
| コリアンダー | 小さじ3 |
| カルダモン | 小さじ1/2 |
| シナモン | 小さじ1/2 |
| ジンジャー | 小さじ1/4 |
| カイエンペッパー | 小さじ1/4 |
| クローブ | 小さじ1/8 |
| フェンネル | 小さじ1/8 |

## 作成メモ

シナモンを減らすのではなく、クミンとコリアンダーをそれぞれ小さじ1追加し、香りの土台を強化した。

## 感想

- 日が経ってスパイスの香りが飛びつつある料理への補完としては十分だった。
- カイエンペッパーだけを別にして、料理ごとに辛さを調整できる構成も検討したい。

## 次回調整候補

- シナモンを小さじ1/2から小さじ1/4へ減らす。
- フェンネルを小さじ1/8と小さじ1/4で比較する。
- カイエンペッパーは料理ごとの辛さに応じて調整する。
- クローブは現状を維持する。増やしすぎない。
